# TwinVerse — Beta pubblica

Demo sperimentale: https://twinverse-game.github.io/

Questo repository contiene esclusivamente il pacchetto web di una versione approvata per il beta testing. Non è il repository di sviluppo.

Release: `demo-4-rc-2026-11-07`. Sorgente runtime: `3a4f1dd8d0c7d48a88ca2c92825f7f91dd3ae378`.

Controlli: WASD/frecce movimento, O azione/calcio/continua, K scatto esplorativo/pugno, Spazio salto, Z parata temporizzata, Invio pausa. Su smartphone usare i controlli a schermo in verticale o in orizzontale. Toccare «Attiva audio» se il browser richiede un gesto per riprodurre la traccia V8.

Pubblicazione manuale: Pages serve main dalla radice. Nessun workflow riceve commit dal repository di sviluppo. Ogni nuova build richiede approvazione del proprietario, controlli locali, pacchetto selezionato e push ordinario a questo repository. Non copiare sorgenti, documenti di produzione, credenziali o asset archiviati.

I file distribuiti per il browser sono pubblici e scaricabili. robots.txt/noindex limitano l'indicizzazione cooperativa, non l'accesso.
